# Plan · Asistente con LLM

1. Entrevistar usuarios sobre la ayuda que realmente necesitan: seguimiento, preparación de entrevista o resumen de progreso; elegir un flujo.
2. Implementar y probar plantilla sin LLM como referencia.
3. Diseñar contrato de contexto mínimo, controles de acceso y aislamiento de texto externo.
4. Elegir proveedor tras revisar costo, privacidad y disponibilidad; usar clave de servidor y mocks en CI.
5. Evaluar con casos sintéticos y revisión humana; habilitar solo como función optativa y con explicación de límites.
