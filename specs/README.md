# Especificaciones del producto

Cada incremento tiene una especificación del problema y criterios de aceptación (`spec.md`), una secuencia de implementación (`plan.md`) y tareas verificables (`tasks.md`). Las tareas se marcan completas solo con evidencia, no porque el documento exista.

| Incremento | Objetivo | Estado |
|---|---|---|
| [001 Seguimiento accionable](001-seguimiento-accionable/spec.md) | Agenda real y siguiente acción consistente | Propuesta. |
| [002 Descubrir empleos](002-busqueda-empleos/spec.md) | Consultar Jooble Perú sin dar autoridad al proveedor sobre postulaciones | Código inicial; validación externa pendiente. |
| [003 Asistente de carrera](003-asistente-carrera/spec.md) | Borrador de seguimiento con contexto autorizado y revisión humana | Diseño, no implementado. |
| [004 Identidad y trazabilidad](004-identidad-y-trazabilidad/spec.md) | Visibilidad de contraseña, diagnóstico SQL y pertenencia estricta | Código y migración; validación con SQL local pendiente. |

El [roadmap](../docs/11-ROADMAP.md) contiene fases posteriores sin convertirlas en requisitos del MVP.
