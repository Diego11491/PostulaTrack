# Registro de decisiones

Las decisiones explican el problema, la opción elegida y qué tendría que pasar para reconsiderarla. No equivalen a un despliegue.

| ADR | Decisión | Estado |
|---|---|---|
| [ADR-001](001-monolito-modular.md) | Web, API modular y SQL Server en un solo producto | Aceptada para MVP. |
| [ADR-002](002-fuente-de-verdad.md) | SQL Server como fuente de verdad, historial en transacción | Aceptada para MVP. |
| [ADR-003](003-nube-opcional.md) | Primero valor y validación local; Azure solo con motivo y presupuesto | Aceptada para MVP. |
| [ADR-004](004-busqueda-externa.md) | Consultar Jooble sin delegar la verdad de los procesos | Aceptada para la integración inicial. |
| [ADR-005](005-llm-asistido.md) | IA opcional, borrador con revisión humana | Propuesta, aún no implementada. |

Una decisión aceptada define dirección; las puertas de evidencia de [estado](../07-ESTADO-Y-EVIDENCIA.md) siguen aplicando.
