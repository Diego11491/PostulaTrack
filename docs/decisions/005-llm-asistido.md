# ADR-005 · Asistencia de redacción con revisión humana

**Estado:** propuesta, sin despliegue. **Fecha:** 2026-10-04.

El valor potencial del LLM es redactar el siguiente seguimiento usando datos de la candidatura autorizada, sin inventar decisiones de empleadores. Se comparará contra una plantilla simple. Si se valida, el asistente ofrecerá solo un borrador optativo que el usuario revisa, edita y envía por sí mismo. No cambiará estados ni enviará solicitudes en nombre del usuario.

**Condiciones:** permisos por propietario, datos mínimos, protección frente a instrucciones en ofertas externas, presupuesto y evaluación humana. La [especificación 003](../../specs/003-asistente-carrera/spec.md) define las puertas antes de implementarlo.
