# Política de seguridad

No publiques credenciales, cadenas de conexión, volcados de datos personales ni archivos `.env` en incidencias o commits.

Para reportar una vulnerabilidad durante el proyecto académico, comunícala de forma privada al responsable del repositorio e incluye pasos mínimos de reproducción. No uses datos reales de estudiantes durante las pruebas.

Antes de desplegar públicamente deben completarse las medidas indicadas en `docs/03-seguridad.md`, especialmente HTTPS, gestión de secretos, recuperación de contraseña, MFA administrativo y pruebas OWASP.
